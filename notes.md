# Public Notes

Moirai is the Music Mentor of The Refrain within the Verve N Veda ecosystem.

This public repository contains material intended for the public Moirai experience. Public documentation is limited to:

- Moirai's public identity and role
- user-facing music and creative features
- public resources and navigation
- creator rights and authorship boundaries
- general accessibility and usage information

Private development notes, internal implementation details, administrative controls, security information, private service locations, backend architecture, internal routing, and non-public system documentation are intentionally not published here.

Historical development material is preserved separately in private project records.
